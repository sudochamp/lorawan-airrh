# Design Requirement

- E-ink display to display temperature (skeuomorphic would be cool)
- QR code for setup with mobile, using LoRaWAN OTAA join (no WiFi/Bluetooth)
- Slim, low power, battery operated.
    - 1 year battery life or more
- Should work in harsh environments.
    - IP54
    - Target use: FMCG and general storage/warehouse environments (not extreme industrial, e.g. no molten steel)
- This needs to be a very capable device, but still cheap
- Temp and humidity are a must
- Local datalogging (onboard flash, not SD card)
- CO2 / NOx sensing dropped from this model. Candidate for a higher-range variant
